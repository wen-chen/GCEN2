GCEN2 Documentation
===================

**GCEN2** is a Python toolkit for gene co-expression network analysis: the
GCEN commands, WGCNA and hdWGCNA module analysis, single-cell and spatial
transcriptomics, multi-omics and trajectory networks, publication figures and
reports, with C++ kernels for speed.

.. code-block:: bash

   pip install gcen2[all]
