GCEN2

Gene co-expression network analysis from bulk to single-cell and spatial transcriptomes

One command-line tool and Python package for co-expression networks, WGCNA and hdWGCNA modules, single-cell, spatial, trajectory and multi-omics analyses, with publication figures. It gives the same results as the established tools, faster.

Quick start

The GCEN pipeline, in GCEN2

On the GCEN sample data in data/example/bulk/: normalize, filter, build the network, find modules, annotate them, rank genes from seeds, and write a report.

Command line

{{ code([ "EX=GCEN2/data/example/bulk", "gcen2 normalize -i $EX/gene_expr.tsv -o norm.tsv -m tmm", "gcen2 filter -i norm.tsv -o filt.tsv -p 0.75", "gcen2 build -i filt.tsv -o net.network -m spearman -c 0.8 -p 0.001 -f -t 8", "gcen2 module -i net.network -o modules.txt -s 0.5 -t 8", "gcen2 annotate -g $EX/go-basic.obo.gz -a $EX/gene_go.assoc.gz -n net.network -o annotation/", "gcen2 rwr -n net.network -g $EX/rwr_seed_genes.list -o rwr.tsv", "gcen2 report -n net.network -m modules.txt -o report.html", ], "the quick start commands") }}

Python
