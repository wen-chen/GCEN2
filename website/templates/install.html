From the source code

Needs a C++17 compiler and CMake (pip fetches CMake if it is missing): GCC or Clang on Linux, Xcode command-line tools on macOS, Visual Studio Build Tools on Windows.

{{ code(["git clone " ~ site.github, "cd GCEN2", 'pip install ".[all]"'], "the source installation", prompt=True) }}

From PyPI

Pre-built wheels for the three platforms; no compiler needed.

{{ code(['pip install "gcen2[all]"'], "the pip command", prompt=True) }}

From Bioconda

On Linux and macOS. Bioconda does not build packages for Windows; use pip there.

{{ code(["conda install -c conda-forge -c bioconda gcen2"], "the conda command", prompt=True) }}

Example data

The repository has example data for every tutorial in data/example/:

  • bulk/ — the GCEN sample data (expression matrix, GO and KEGG annotation, gene lists);
  • single_cell/ — 1,800 cells of three cell types from the 10x PBMC 10k data set (.h5ad);
  • spatial/ — a 10x Visium section of the mouse brain, 2,695 spots and 2,000 genes (.h5ad).

GO and KEGG annotation

GO annotations for most model organisms are available from the Gene Ontology Consortium, and go-basic.obo with them. KEGG annotations of protein-coding genes can be obtained with KAAS; InterProScan gives both for proteins. The GCEN download page provides annotation files for human, mouse and zebrafish and the KEGG information file K2ko.tsv; GCEN2 reads them unchanged.
