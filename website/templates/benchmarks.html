How they were run

  • One machine with 16 cores; every time measured while the machine was otherwise idle.
  • The same input files and parameters for both tools; the versions of the reference tools as listed.
  • "Same" means identical edges, module assignments (adjusted Rand index 1) or statistics within the precision of the files; where a step is random (metacells), the tools are compared on the same metacells and seed to seed.
